# Keep Jev judgments inside deterministic policy

Use the official TypeSafe SDK with OpenRouter's native route if compatibility validates, and retain deterministic admission and completion decisions in PI Lead. Typed SDK responses do not prove runtime validity or semantic correctness, and gateway confidence fields may be missing; constrain candidates, validate responses and recheck current authorization before acting. The $1/day ceiling approved for Jev is an upper bound rather than a target. This deliberately limits autonomous judgment instead of giving it permissions, model names or arbitrary commands to choose freely. See [Jev contracts](../research/jev-contracts.md) and the [specification](../../.scratch/pi-lead/spec.md).
